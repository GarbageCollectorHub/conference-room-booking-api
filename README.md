# Conference Room Booking API

API для оренди конференц-залів: керування залами, пошук вільних, бронювання
з розрахунком вартості.

## Як запустити

Потрібні .NET 9 SDK і SQL Server LocalDB

1. Відкрити `RoomBooking.sln`, стартовий проєкт — `RoomBooking.Api`.
2. Запустити (F5).

База створюється автоматично при першому запуску: застосовуються міграції і додаються
три зали з послугами. Додаткового налаштування не потрібно: рядок підключення до LocalDB
лежить у `appsettings.json`, початкові дані — у `RoomBooking.Infrastructure/Persistence/SeedData.cs`.


## Тарифи

| Час         | Множник			|
|-------------|---------		|
| 06:00–09:00 | −10%			|
| 09:00–18:00 | базова ставка	|
| 12:00–14:00 | +15%, перекриває базовий |
| 18:00–23:00 | −20%			|

## Як рахується вартість

1. `TariffSchedule` ріже бронювання в точках, де змінюється тариф. 11:00–15:00 дає три
   частини: 11:00–12:00, 12:00–14:00, 14:00–15:00.
2. Для кожної частини визначається тариф. Де інтервали накладаються, перемагає той,
   у якого вищий `Priority`.
3. `RentalPriceCalculator` рахує кожну частину як `ставка × множник × години`
   і округлює до копійок.
4. `BookingPrice` збирає частини, додає разову вартість обраних послуг і рахує підсумок.

## Правила бронювання

- Час — у межах 06:00–23:00 місцевого часу залу, початок і кінець на цілу годину.
  Інакше запит відхиляється з 400.
- Зал не можна забронювати на зайнятий час. Перевірка вільного часу і збереження
  виконуються в одній транзакції, тож два одночасні запити не забронюють один зал
  на один і той самий час.
- Зал з майбутніми бронюваннями видалити не можна.

## Час і часові пояси

Бронювання зберігаються в UTC, а тарифи рахуються за місцевим часом залу — у `Room`
для цього є `TimeZoneId`. Запит на бронювання приймає час зі зміщенням
(`DateTimeOffset`), у відповіді час повертається в UTC, а розбивка вартості —
у місцевому часі залу, бо саме в ньому задані тарифи.
